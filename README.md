# Sylhet_Air_Quality_NDVI_ML_Project
This project investigates whether satellite-measured vegetation cover (NDVI) helps predict daily PM2.5 air pollution in Sylhet, Bangladesh. Using four years of real weather, soil, and satellite data, three machine learning models were trained and compared — with Linear Regression performing best (R² = 0.822) — and a direct test showed that adding NDVI provided no meaningful improvement in prediction accuracy over weather alone.

A machine learning study testing whether satellite-derived vegetation greenness (NDVI) improves prediction of daily PM2.5 air pollution in Sylhet, Bangladesh. The project combines real data from three independent sources — Open-Meteo (air quality/weather), NASA POWER (solar radiation/soil moisture), and Google Earth Engine (Sentinel-2/MODIS NDVI) — spanning 1,400 days (2022–2026). Three models (Linear Regression, Random Forest, XGBoost) were trained with a time-based train/test split to mimic real forecasting conditions. Linear Regression performed best (R² = 0.822), and removing NDVI-related features changed error by less than 0.1 µg/m³ — showing that, in this dataset, weather and recent pollution history are far stronger predictors of air quality than vegetation cover.
